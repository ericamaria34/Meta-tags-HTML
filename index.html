Meta Tags, Elementos e Atributos HTML

Meta tags são linhas de código HTML que fornecem informações sobre a página web para navegadores e motores de busca. Localizadas na seção do documento HTML, elas não aparecem visualmente na página, mas têm um impacto profundo na forma comoo site é exibido e percebido em diferentes plataformas.

Metas tags utilizadas no head do HTML

  • <meta charset="UTF-8">: Define o conjunto de caracteres utilizado na página.
  • <meta name="viewport">: Controla o dimensionamento e a escala da página em dispositivos móveis, fundamental para responsividade.
      • content=
    • "width": Define a largura em pixel de um viewport
    • "height": Define a altura em pixel de um viewport
    • "initial-scale": Define a relação entre a largura do dispositivo (largura do dispositivo no modo retrato ou altura do dispositivo no modo paisagem) e o tamanho da janela de visualização
    • "maximum-scale": Define o valor máximo de zoom, deve ser maior ou igual aominimum-scale ou o comportamento sera indeterminado
    • "minimum-scale": Define o valor mínimo do zoom, deve ser menor ou igual ao maximum-scale ou o comportamento sera indeterminado
    • "user-scalable": Define se o usuário pode ou não aumentar ou diminuir o zoom da página, os valores possíveis são "yes" e "no"
  • <meta name="description">: Fornece uma descrição curta da página, utilizada pelos motores de busca.
  • <meta name="author">: Especifica o autor da página.;
  • <meta name="referrer">: Controle as informações enviadas no cabeçalho HTTP Referer, protegendo os dados dos usuários.
  • <meta name="content-security-policy": Preveni ataques de scripts maliciosos ao especificar quais fontes de conteúdo são confiáveis.
  • <meta name="robots">: conjunto de orientações para controlar como os robôs dos mecanismos de busca rastreiam e indexam as páginas do site.
  • <meta name="keywords">: Lista palavras-chave relevantes para a página, usadas pelos motores de busca.
  • <meta name="theme-color">: Personalize a cor da barra de endereço em navegadores móveis
  • <meta name="color-scheme">: Adapta site aos modos claro e escuro, ajustando-se automaticamente às preferências do usuário.
  • <meta name="favicon">: Especifica o ícone da página exibido na aba do navegador

Protocolo Open Graph

Define como as páginas de um site aparecem ao serem compartilhadas em redes sociais e aplicativos de mensagens

  • <meta property="og:title">: Define o título da página
  • <meta property="og:description">: Fornece uma descrição
  • <meta property="og:image">: Especifica a URL de uma imagem que será exibida
  • <meta property="og:url": Define url, como seu ID permanente.

Elementos de formulário HTML:

  • color: Especifica uma cor para um elemento
  • date: Permite que o usuário selecione uma data
  • datetime-local: Permite que o usuário selecione uma data e hora local
  • email: Permite que o usuário insira um endereço de e-mail
  • file: Permite que o usuário selecione um arquivo
  • hidden: Define um campo oculto
  • image: Permite que o usuário selecione uma imagem
  • month: Permite que o usuário selecione um mês
  • number: Permite que o usuário insira um número
  • range: Permite que o usuário selecione um valor dentro de um intervalo
  • search: Permite que o usuário insira uma consulta de pesquisa
  • tel: Permite que o usuário insira um número de telefone
  • time: Permite que o usuário selecione uma hora
  • url: Permite que o usuário insira um URL
  • week: Permite que o usuário selecione uma semana

Atributos de formulário HTML:

  • action: Define a URL para onde os dados do formulário devem ser enviados
  • target: Define onde o resultado do formulário deve ser exibido
  • method: Define o método HTTP a ser usado ao enviar o formulário
  • autocomplete: Define se o campo deve ter preenchimento automático
  • value: Define o valor inicial do campo
  • readonly: Define se o campo deve ser somente leitura
  • disabled: Define se o campo deve estar desativado
  • size: Define o tamanho do campo
  • maxlength: Define o número máximo de caracteres permitidos no campo
  • multiple: Define se o campo deve permitir a seleção de múltiplos valores
  • placeholder: Define um texto de exemplo que aparece no campo quando ele está vazio
  • required: Define se o campo deve ser obrigatório
  • autofocus: Define se o campo deve receber foco automaticamente
